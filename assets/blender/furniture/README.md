# Interior furnishings

Twenty-seven Kenney Furniture Kit assets, CC0, from https://kenney.nl/assets/furniture-kit.
Original GLBs and licence: `assets/sources/furniture/`. Recipe: `tools/prepare_furniture.py`, run with background Blender 5.2. Models retain source mesh sections and palettes. Consistent 2x metre conversion; the differently scaled toilet is normalized to 0.82 m high. Origins are centred horizontally and sit on the floor. Runtime templates recenter around physical box bounds.

The original MPFB crowd supplies residents; no second set of human textures or skeleton assets is loaded. Their individual skeletons, animation mixers, IK contacts and ragdolls are independent instances.
