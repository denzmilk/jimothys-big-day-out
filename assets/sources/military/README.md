# Military sources

- **Tank** by Quaternius, [Animated Tanks Pack](https://quaternius.com/packs/animatedtanks.html), CC0. Original `Tank.blend` and accompanying `Quaternius-License.txt` retained. Direct source file ID: `1uaTlQ-HqN27if0knwsGTpL2NiQKFEKms` in the publisher's linked Drive folder.
- **Jet** by **jeremy**, [Poly Pizza model](https://poly.pizza/m/6fyLMORhgGK), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Original delivery `Jet.glb` retained. Publisher resource: `https://static.poly.pizza/19d58465-dafb-4df0-a3b8-b0500bd9ed4b.glb.br`. Creator: https://jeremy.toys. Attribution also ships in the public model folder.

Downloaded 2026-10-02. `tools/build_military.py` opens these in Blender and converts original faces/colours into game sections. Changes: metre scale (7.2 m tank, 13 m jet), +Z heading, centred footprint/ground baseline, baked source pose/vertex colours, separate breakable tracks/hull/turret/barrel and wings/fuselage/tail. Editable converted Blender files are in `assets/blender/military`; GLBs and measurements are in `public/assets/models/military`. No claim is made that the static tank delivery preserves the source's track animation.
