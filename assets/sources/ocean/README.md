# Ocean sources

Quaternius [Ships](https://quaternius.com/packs/ships.html) and [Animated Fish](https://quaternius.com/packs/animatedfish.html), downloaded 2026-10-02, CC0 1.0. Original Blender files and publisher licences are retained here.

`tools/prepare_ocean.py` converts old diffuse materials, scales to metres, preserves fish armatures and Swim clips, and separates original boat faces into breakable sections. Editable deliveries live in `assets/blender/ocean`; GLBs and a manifest in `public/assets/models/ocean`.
