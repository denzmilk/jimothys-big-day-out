# Police response sources — M60

Downloaded and licence-checked 2026-10-04:

- Kenney Car Kit 3.1, https://kenney.nl/assets/car-kit — CC0. Selected original `police.glb` and its palette are in `assets/vehicles/kenney-source`. The car licence is also retained here as `car-kit-License.txt`.
- Kenney Blaster Kit 2.1, https://kenney.nl/assets/blaster-kit — CC0. Original selected `blaster-a.glb`, its `Textures/colormap.png` and `blaster-kit-License.txt` are retained here.
- Police cap: original project model generated by `tools/build_police_equipment.py`; no external source.

Rebuild with Blender:

```
VEHICLES_ONLY=police /Applications/Blender.app/Contents/MacOS/Blender --background --python tools/prepare_vehicles.py
/Applications/Blender.app/Contents/MacOS/Blender --background --python tools/build_police_equipment.py
/Applications/Blender.app/Contents/MacOS/Blender --background --python tools/preview_police_assets.py
```

Editable `.blend` files are in `assets/blender/vehicles` and `assets/blender/people/response`. Runtime GLBs are in the corresponding `public/assets/models` directories. The car uses the existing metre-scale, glass and wheel preparation. The compact firearm keeps its palette, is scaled to 0.44 m long, and points along runtime +Z. The cap is built with explicit Principled materials so its navy, visor and badge survive export.

Do not put the car source alongside the firearm palette: both upstream GLBs reference a file named `Textures/colormap.png`, but those two textures differ.
